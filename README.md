# Social Network Analytics: NetworkX Lab (MBEL6275)

Amazon co-purchase network (24,839 products, 73,981 links) analysed in Python.

## Start in 4 clicks
1. Click the green **Code** button, then the **Codespaces** tab.
2. Click **Create codespace on main**. Wait 2 to 3 minutes while it builds.
3. Open `notebooks/01_networkx_demo.ipynb`.
4. If asked, choose the kernel **Python 3**. Click a cell and press **Shift + Enter**.

## Files
- `data/` the two CSV files from your Gephi assignment
- `notebooks/01_networkx_demo.ipynb` the class demo
- `notebooks/02_compare_with_gephi.ipynb` type your Gephi numbers, compare with NetworkX
- `notebooks/sna_helpers.py` small helper functions

## When you finish
Codespaces uses a free monthly quota. Close it: bottom-left green button, then **Stop current codespace**.
